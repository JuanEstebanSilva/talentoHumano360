# Directorio de Documentación de Talento 360
## Gobernación de Boyacá

Este directorio contiene recursos complementarios de diseño, lineamientos de seguridad y manuales de despliegue en la nube para la plataforma **Talento 360**:

---

## 📂 Contenido del Directorio

- **[`branding/`](./branding/):** Manual de marca institucional, paleta oficial de colores y logotipos de la Gobernación de Boyacá.
- **[`screenshots/`](./screenshots/):** Muestrario fotográfico de las interfaces de usuario (Dashboard, Directorio, Viáticos, Horarios, Trámites).
- **[`DEPLOY_NETLIFY_RENDER.md`](./DEPLOY_NETLIFY_RENDER.md):** Guía técnica para despliegues opcionales en infraestructura cloud pública (Render + Netlify).
- **[`SECURITY.md`](./SECURITY.md):** Políticas de ciberseguridad, reporte de incidentes y cumplimiento de estándares institucionales.
