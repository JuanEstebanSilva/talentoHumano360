# Identidad Visual y Recursos de Marca — Talento 360

Este directorio contiene los recursos gráficos oficiales y guías de identidad corporativa de la **Gobernación de Boyacá** y la **Secretaría General - Subdirección de Talento Humano** utilizados como base para el diseño visual de la plataforma **Talento 360**.
